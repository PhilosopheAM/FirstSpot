## 风格约束

- 必须匹配 Myo 现有形象：简约线条、粗黑圆润笔触、奶白猫身体、粉色小嘴、浅薄荷背景色块。
- Myo 必须作为主体出现，画面占比约 50% 以上。
- 卡片文字只使用简体中文和阿拉伯数字；不使用英文、拼音、繁体字或真实品牌。
- 不出现真实股票名称、基金名称、券商 Logo、收益承诺、买卖建议。
- 画面应适合移动端卡片裁切，主体居中，留白明确。
