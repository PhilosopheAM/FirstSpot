| `一级市场` | `一级市场`                            | 公司或发行人第一次把证券卖出去融资的地方。           | 像新店第一次卖会员卡，钱直接进店里。             |
| `证券`   | `证券`、`已发行证券`                      | 代表某种权益或债权的凭证，常见有股票、债券、基金份额。     | 它像一张“你拥有某种金融关系”的票据。            |

| `债券`   | `债券`                              | 借钱给发行人的凭证，到期和利息规则写在产品条款里。       | 更像一张借条，但仍要看借款方信用和利率变化。         |
| `场内基金` | `场内基金`、`ETF`、`指数基金`、`宽基指数`、`宽基`   | 可以在交易所买卖的基金，很多产品会跟踪一篮子股票或债券。    | 像买一个透明篮子，而不是只押一个水果。            |
| `指数基金` | `指数基金`、`ETF`、`场内基金`               | 按照指数规则持有一篮子资产的基金，目标是尽量跟踪某个指数表现。 | 像照着菜谱装篮子，规则比故事更重要。             |
| `宽基`   | `宽基`、`宽基指数`                       | 覆盖较广市场代表性资产的指数类型，通常比行业或主题更分散。   | 像买市场大篮子，而不是只买一个货架。             |
| `流动性`  | `流动性`                             | 想买或想卖时，能不能比较顺利成交。               | 像门能不能打开。门好开，不代表屋里一定有宝贝。        |
| `交易所`  | `交易所`、`沪市`、`深市`、`北交所`、`上交所`、`深交所` | 组织证券买卖、制定交易规则的市场场所。             | 像有规则和门牌号的集市。                   |
| `板块`   | `板块`、`主板`、`创业板`、`科创板`             | 把相似市场、行业或规则下的公司放在一起看的分类。        | 像城市里的不同小区，规则和风险气质会不一样。         |
| `交易时间` | `交易时间`、`交易时段`、`连续竞价`、`集合竞价`       | 市场允许集中成交的时间窗口，不是全天都按同样规则交易。     | 像快递揽收时间，错过窗口就要等下一段。            |
| `市价委托` | `市价委托`、`市价单`                      | 优先追求尽快成交的下单方式，实际成交价可能和预想不同。     | 像说“现在能买到就买”，速度更快，但价格不一定最舒服。    |
| `涨跌幅`  | `涨跌幅`、`涨跌停`                       | 单个交易日价格上下波动的规则边界，不同板块可能不同。      | 像给价格装护栏，但护栏不等于不会跌。             |
| `K 线`  | `K 线`、`行情图`、`分时`、`日线`、`周线`        | 记录价格变化的图，不是预测未来的水晶球。            | 像体温记录表：记录变化，但不能单独诊断全部问题。       |
| `成交量`  | `成交量`                             | 某段时间里成交了多少，代表交易活跃程度。            | 像店里人流量变大，只说明热闹，不代表商品一定更好。      |
| `估值`   | `估值`、`低估值`                        | 把价格和利润、资产、分红、成长放在一起看，判断贵不贵。     | 同样 100 元，买水可能贵，买外套可能合理。        |
| `市盈率`  | `市盈率`、`PE`                        | 市场愿意为公司每 1 元利润付多少价格。            | 像“利润价格标签”，但不能单独决定能不能买。         |
| `市净率`  | `市净率`、`PB`                        | 价格和公司净资产之间的比例。                  | 像看这家公司账面家底和市场标价的关系。            |
| `股息率`  | `股息率`、`分红`                        | 每年现金分红相对当前价格的大致比例。              | 像房租回报率，但分红不是永远固定。              |
| `现金流`  | `现金流`、`经营现金流`                     | 公司真金白银流进流出的情况，是观察利润质量的重要线索。     | 账面说赚钱了，也要看钱有没有真的收回来。           |
| `负债`   | `负债`、`资产负债率`                      | 公司欠的钱和杠杆压力，过高时会增加经营风险。          | 像家庭贷款，收入稳定时能承受，压力太大就危险。        |
| `市场风险` | `市场风险`、`系统性波动`、`大盘波动`             | 整个市场环境变化带来的波动，单靠买很多家公司也不能完全消除。  | 像下大雨，路上大多数人都会被影响。              |
| `公司风险` | `公司风险`、`单点风险`                     | 单家公司经营、财务或治理出现问题带来的风险。          | 像某一段路塌了，影响的是走这条路的人。            |
| `分散`   | `分散`、`分散投资`                       | 不把钱全压在一个点上，用多个资产降低单点出问题的伤害。     | 像不把所有鸡蛋放进同一个篮子。                |
| `应急金`  | `应急金`、`现金管理`                      | 为突发支出准备的钱，优先安全和随时可用。            | 像家里的备用钥匙，平时不起眼，关键时刻要能用。        |
| `现金管理` | `现金管理`、`应急金`、`货币工具`               | 管理短期和随时可用资金的工具或方法，优先安全性和流动性。    | 像把常用工具放在最容易拿到的位置。              |
| `固收`   | `固收`、`短债`、`债基`、`货币工具`             | 以债券、货币等低波动资产为主的工具，但也不是完全不波动。    | 像组合里的稳定器，不是加速器。                |
| `债基`   | `债基`、`债券基金`                       | 主要投资债券的基金，会受到利率、信用和期限等因素影响。     | 像把多张借条装进一个产品里，仍要看借款质量。         |
| `权益`   | `权益`、`权益市场`、`权益基金`                | 和股票所有权相关的一类资产，长期可能有成长，但波动通常更明显。 | 像成长仓，需要更长时间和更强承受力。             |
| `从众`   | `从众`、`FOMO`、`错失恐惧`                | 看到别人都在做，就担心自己错过而冲动行动。           | 朋友圈都在晒收益，不代表这就是你的买入理由。         |
| `损失厌恶` | `损失厌恶`                            | 人们通常对亏损更敏感，容易为了不承认亏损而拖延决策。      | 像不愿拆开一张坏成绩单，但不看它也不会变好。         |
| `仓位`   | `仓位`、`仓位上限`、`重仓`                  | 某类资产占你总资金的比例，决定一次波动会伤到你多少。      | 像背包重量，太重时每一步都更累。               |
| `定投`   | `定投`、`微笑曲线`                       | 按固定规则分批投入，降低一次猜时点的压力，但不保证盈利。    | 像每月固定存钱，重点是可承受和长期执行。           |
| `资产配置` | `资产配置`、`组合`、`稳健组合`                | 把现金、固收、权益等放在不同岗位上，让钱服务不同期限和用途。  | 像工具箱：锤子、尺子、螺丝刀各有工作。            |
