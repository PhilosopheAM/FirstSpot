# 12 章概念聊天对话与路径图方法论

更新时间：2026-04-28

## 目标

新手村教程的“概念”环节采用 Myo 聊天式问答。用户不只是点亮卡片，而是在 Myo 设置的情景里选择自己的疑问，借由“情景 - 用户提问式选项 - Myo 反馈 - 下一必经概念”的节奏学习本章核心概念。

本轮重构目标：

- 将 12 章概念脚本从“普通分支问答”重构为“概念路径图驱动”的必经节点。
- 每章由 7 个 Myo 问答节点组成，每个节点 3 个用户选项；用户看到不同表达，但都会收束到同一教学目标。
- 对话轮次限制放宽到 50 轮；当前每章完整路径约 14 轮（Myo 7 轮 + 用户 7 轮），为后续扩展保留空间。
- CH01-CH12 全部接入“概念”卡片聊天入口，完成对应章节概念对话后自动点亮概念学习步。

## 方法论：让用户“主动问出”必学概念

### 1. 必经节点，不做知识点赌博

每章先确定不可跳过的概念节点。用户选项可以有不同语气和关注点，但节点推进顺序固定，确保不会因为用户选择不同而漏掉核心概念。

设计原则：

- 每个节点只承担一个主要教学目标。
- 用户选项是“提问式表达”，不是考试答案。
- Myo 的反馈把三个选项收束到同一个概念命名或概念关系。
- 节点之间按“直觉场景 -> 小矛盾 -> 概念命名 -> 误区澄清 -> 行动规则”推进。

### 2. 伪分支，真收束

用户看到 3 个选择，但 3 个选择都导向同一概念目标。例如 CH01 的流动性节点：

| Myo 情景 | 用户可选疑问 | 收束概念 |
| --- | --- | --- |
| 想买没人卖，想卖没人接 | 那我是不是买不到或卖不掉？ / 是不是要降价才能卖出去？ / 交易的人越多会不会更顺？ | 流动性 |

这样保留互动感，同时避免关键对话无法触发。

### 3. Myo 的情景设置公式

Myo 每次引导尽量使用以下结构：

1. 先给生活化场景或市场小困境。
2. 暴露一个新手会自然困惑的矛盾。
3. 让用户用口语化选项问出来。
4. Myo 回应并命名概念。
5. 用一句行动规则收束。

示例：

```text
Myo: 你想买一只股票，但没人愿意卖；或者你急着卖，却没人愿意接。你会先问什么？
用户: 那我是不是就买不到或卖不掉？
Myo: 这正好引出“流动性”：想买或想卖时，能不能比较顺利成交。
```

### 4. 用户选项写法

优先使用真实疑问或自我总结：

- “那我是不是就买不到或卖不掉？”
- “这是我的理由，还是别人的情绪？”
- “低估值也可能是陷阱？”
- “先有系统，再谈行动。”

避免使用过于教材化的选项：

- “我想了解流动性。”
- “请选择市盈率定义。”
- “学习资产配置概念。”

## 交互模式

1. 用户进入某章节详情页，点击“概念”卡片的“进入概念对话”。
2. 聊天框从页面上方飞入，顶部左侧提供返回按钮。
3. Myo 消息在左侧显示，用户可选回答以右侧竖向选项卡显示。
4. 用户点击选项后，该选项进入右侧聊天气泡，Myo 先显示约 0.8s 的“...”思考气泡，再给出反馈。
5. Myo 的反馈按句段逐段出现，不一次性堆出多段文本；当一次反馈包含多段时，第一段之后继续显示“...”思考气泡，并根据上一段长度停留约 1s-2.5s 后再出现下一段。
6. 当前节点的 Myo 反馈全部出现后，再展示下一节点的 Myo 提问和用户选项。
7. 点击左上角返回章节学习页时，对话进度保存在当前页面状态中。
8. 再次点击“概念”卡片时，聊天框从上方飞入，并从上次选择后的节点继续。
9. 全部节点完成后，Myo 用表扬气泡告知用户已经了解本章核心概念，底部出现“返回章节”按钮。
10. 用户点击“返回章节”后，聊天框以向上滑动的收纳盒效果离开，返回章节学习页；当前章节“概念”学习步保持点亮。

## 术语交互

聊天文本中首次承担教学任务的专业词继续使用词汇表词卡模式：

- 浅蓝色词卡突出显示。
- 点击词卡弹出 Myo 白话解释。
- 解释内容来自 `guidance_glossary.dart`。
- CH01-CH12 概念对话全部参与术语首次出现扫描，保证概念聊天成为术语解锁的正式入口。

## 12 章概念路径图

完整脚本维护在：

`testapp/lib/features/learning_guidance/data/guidance_concept_dialogues.dart`

每章 7 个 Myo 问答节点，每个节点 3 个用户回答选项。节点按必经路径推进，完整对话低于 50 轮。

| 章节 | 概念路径图（必经节点） | 设计意图 |
| --- | --- | --- |
| CH01 什么是二级市场 | 资金流向 -> 一级/二级市场 -> 交易角色 -> 买不到/卖不掉 -> 流动性澄清 -> 价格形成 -> 总结 | 用“想买没人卖/想卖没人接”引导用户主动问出流动性。 |
| CH02 沪深北交易所与板块 | 代码门牌 -> 市场街区 -> 板块差异 -> 前缀不是推荐 -> 门槛/涨跌幅 -> 风险标识 -> 查规则清单 | 把代码前缀从“背诵点”转成“下一步查什么”的行动路径。 |
| CH03 交易账户与规则 | 交易安全带 -> 交易时间 -> 买入后退出限制 -> 限价/市价 -> 涨跌幅 -> 下单检查 -> 交易前清单 | 让新手先装刹车，再理解按钮。 |
| CH04 行情与基础图形 | K 线是记录 -> 开高低收 -> 成交量 -> 周期镜头 -> 单图不重注 -> 图表提问器 -> 安全句 | 避免把图形当预测机器，引导用户把图表变成证据之一。 |
| CH05 估值入门 | 价格 vs 价值 -> 小店利润比喻 -> PE -> PB/股息率 -> 行业参照 -> 低估值陷阱 -> 指标路径 | 让用户先问“指标回答什么”，再看数字。 |
| CH06 认识上市公司 | 业务/赚钱方式 -> 公司简历 -> 利润和现金流 -> 负债 -> 竞争持续性 -> 公司风险 -> 研究顺序 | 先体检，再报价，避免题材替代研究。 |
| CH07 风险从哪里来 | 风险来源 -> 市场/公司风险 -> 分散边界 -> 仓位/杠杆 -> 现金缓冲 -> 风险上限 -> 工具匹配 | 先分类风险，再匹配分散、仓位、现金等工具。 |
| CH08 指数基金与场内基金 | 透明篮子 -> 宽基/行业/主题 -> 指数规则 -> 费率/规模/跟踪/流动性 -> 场内交易体验 -> 不闭眼买 -> 筛选路径 | 把“买一篮子”拆成规则、分类、筛选和期限匹配。 |
| CH09 固收与现金管理 | 应急金 -> 资金期限标签 -> 固收也波动 -> 利率/信用/期限 -> 底层资产 -> 短期钱保护 -> 工具路径 | 让用户把钱按用途分层，而不是按收益率排行选择。 |
| CH10 情绪陷阱 | 从众/FOMO -> 群聊晒收益场景 -> 损失厌恶 -> 过度自信/仓位 -> 三个工具 -> 规则前置 -> 暂停键 | 用具体情绪场景引导用户把冲动转成规则。 |
| CH11 定投与长期主义 | 定投不是魔法 -> 固定金额比喻 -> 微笑曲线前提 -> 计划要素 -> 收入不稳处理 -> 暂停/复盘 -> 长期规则感 | 把定投从“保证盈利”纠偏为“可执行规则”。 |
| CH12 搭建稳健组合 | 现金/固收/权益岗位 -> 资金用途和期限 -> 三层资金 -> 比例来自承受力 -> 再平衡 -> 系统草稿 -> 终章路径 | 收束 12 章为个人投资系统草稿。 |

## 后续扩展

- 如果某章后续需要更强分支感，可在单个必经节点内增加“短反馈差异”，但不要改变必经概念顺序。
- 如果每章节点超过 10 个，需重新检查是否仍低于 50 轮，并避免移动端完成压力过高。
- 跨 App 重启后的概念对话持久化仍可后续接入 `shared_preferences`。
