## 2. 体验问题与调整原则

### 2.1 现有问题

- 现有前端详情页主要展示章节简介、学习目标、关键点和题目，用户容易感觉“打开就是答题”。
- 小测承担了过多学习功能，容易让新手把投资者教育误解为考试。
- 奖励反馈已经存在卡片解锁文案，但没有明确表达“完成学习后，用小测领取奖励和下一章通行证”。

### 2.2 新原则

1. **先教育**：每章先完成概念解释、案例说明、轻量互动，降低零基础用户的理解门槛。
2. **再小测**：小测固定放在每章最后，作为知识确认、奖励领取和下一章通行证。
3. **强反馈**：每次互动都给温暖反馈；答错不扣分，不出现失败羞辱。
4. **奖励感克制**：奖励要让用户愿意继续探索，但不能像博彩或交易刺激。
5. **可持续学习**：最终目标是形成长期、分散、低费用、风险可控的投资习惯。

## 3. 每章标准流程

```text
[章节入口]
  ↓
[Myo 开场：共情 + 本章目标]
  ↓
[概念解释：把专业词翻译成生活语言]
  ↓
[案例说明：真实市场或生活类比]
  ↓
[轻量互动：拖拽 / 排序 / 单选 / 滑动条]
  ↓
[本章三件事：关键点复盘]
  ↓
[章末通行证小测：4 题，答对 3 题通过]
  ↓
[奖励反馈：章节卡 + XP + 下一章通行证]
  ↓
[下一章预告 / 回到学习路径]
```

## 4. 12 章教育优先设计摘要

| 章节 | 教育主线 | 案例/类比 | 章末通行证奖励 |
|---|---|---|---|
| CH01 二级市场 | 先理解买卖发生在投资者之间 | 二手平台转让球鞋 | `CARD-01` + 第一章通行证 |
| CH02 交易所与板块 | 股票代码是市场门牌号，不是收益暗示 | 先看小区，再看房子 | `CARD-02` + 地图探索感 |
| CH03 交易规则 | 交易时间、涨跌幅、次日可卖是安全带 | 快递不是 24 小时都揽收 | `CARD-03` + 安全带徽章 |
| CH04 行情与 K 线 | 行情图是记录本，不是水晶球 | 体温记录表 | `CARD-04` + 记录本盖章 |
| CH05 估值入门 | 股价高不等于估值贵 | 同样 100 元买到的东西不同 | `CARD-05` + 估值天平点亮 |
| CH06 上市公司 | 看公司先看它怎么赚钱 | 面试一家公司 | `CARD-06` + 公司简历完成 |
| CH07 风险来源 | 风险来自市场、公司和情绪 | 天气、路况和驾驶员 | `CARD-07` + 风险地图解锁 |
| CH08 指数基金与 ETF | 指数基金是一篮子规则 | 买水果篮，不押单个水果 | `CARD-08` + 篮子收藏 |
| CH09 固收与现金 | 有些钱的任务是站岗 | 学费钱不能坐过山车 | `CARD-09` + 现金锚点 |
| CH10 情绪陷阱 | 情绪正常，动作要慢 | 朋友圈热闹不是买入理由 | `CARD-10` + 暂停键 |
| CH11 定投长期主义 | 定投是执行规则，不保证盈利 | 每月固定存钱 | `CARD-11` + 定投路径 |
| CH12 稳健组合 | 现金、固收、权益各司其职 | 三层工具箱 | `CARD-12` + 12 卡毕业仪式 |
