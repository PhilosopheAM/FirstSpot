# FirstSpot 投资者教育学习框架 · 总览

> 面向中国内地二级市场新手的 12 章学习路径，服务 FirstSpot 产品定位：**不荐股、不加杠杆、强调稳定回报**。
> 本目录每个 `.md` 文件对应一章独立学习内容，供后续内容开发、UX 实现与收藏卡片设计共同参考。

---

## 1. 设计原则

- **新手友好**：默认读者是零基础 18–30 岁年轻人，不预设金融词汇
- **大白话**：用「攒钱买 iPhone」「像抽盲盒」这类生活化比喻替代专业术语
- **强偏向性**：反复强调「长期、分散、低费用、稳定回报」，回避鼓励短线博弈
- **案例驱动**：每章至少 1 个真实 A 股 / 港股案例或贴近生活的类比
- **互动问答**：每个小节嵌入 1–2 道选择题或判断题，即时反馈
- **收藏反馈**：每章完结发放一张「重要概念卡片」，进入收藏品橱窗

## 3. 章节通用结构（内容开发模板）

每个章节 `.md` 文件遵循以下固定结构，方便内容团队并行产出：

1. **章节元信息**：难度 / 预计时长 / 前置章节 / 获得卡片
2. **为什么这一章重要**：一段 3–5 句话的大白话导入
3. **学习目标**：3–5 条可验证的学习成果
4. **核心内容**（2–4 小节，每小节必须包含）：
  - 核心概念（大白话定义 + 生活类比）
  - 真实案例 / 场景演练
  - 1–2 道互动问答
5. **重要概念卡片（收藏品）**：卡片命名、一句话核心、~100 字描述、视觉主题、稀有度
6. **UX 流程**：用户在 App 内完成该章的 8–12 步流程，包含问答失败 / 跳章等分支
7. **小结 & 下一章预告**

## 4. 收藏卡片系统（支持后续橱窗功能）

### 4.1 卡片字段（每章统一）


| 字段    | 说明                    | 用途      |
| ----- | --------------------- | ------- |
| 卡片编号  | `CARD-01` ~ `CARD-12` | 数据库主键   |
| 卡片名称  | 拟人化 / 有记忆点的称号         | 橱窗标题    |
| 核心一句话 | ≤ 40 字                | 正面主文案   |
| 描述文案  | 约 100 字，大白话解释概念       | 背面翻转内容  |
| 视觉主题  | 配色 / 意象 / 角色姿态关键词     | 供美术生成   |
| 稀有度   | 白 / 蓝 / 紫 / 金         | 橱窗排序与动效 |
| 解锁条件  | 完成对应章节学习 + 通关小测       | 触发发放    |


### 4.2 稀有度分级

- **白卡（Common）**：第 1–3 章，奠基概念，人人必得
- **蓝卡（Rare）**：第 4–6 章，工具性概念，需要动手理解
- **紫卡（Epic）**：第 7–9 章，风险与稳定回报核心
- **金卡（Legendary）**：第 10–12 章，心态与长期系统，最难也最重要

### 4.3 橱窗正面展示约定

- 正面：卡片插画 + 卡片名称 + 核心一句话
- 背面（点击翻转）：约 100 字描述 + 获得日期 + 所属章节链接
- 金卡带微动效（如光效、角色动画）以区分价值感

## 5. 章节通用 UX 流程骨架

每章的具体 UX 在各章节文件 `6. UX 流程` 小节细化，但共享以下骨架：

```text
[章节入口 / Guidance_Chapter_Entry]
  ↓ 阅读章节简介 & 难度说明
[概念讲解 / Guidance_Concept_Card_N]   ← 2–4 屏左右滑
  ↓ 每屏结尾出现 1 道互动问答
[案例实训 / Guidance_Case_Study]
  ↓ 情境互动（选择分支 / 模拟操作）
[章末小测 / Guidance_Quiz]
  ↓ 3–5 题随机题库，允许重试
[卡片发放 / Guidance_Reward_Card]
  ↓ 卡片翻转动画 → 加入收藏橱窗
[回首页或进入下一章 / Guidance_Chapter_Next]
```

各章节文件中会在此骨架上补充该章独有的互动细节与文案。
