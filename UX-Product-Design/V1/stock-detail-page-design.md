# 个股/基金详情页 UX 设计文档 (V1)

## 1. 竞品参考与基础功能总结

参考成熟券商与交易软件（如 Robinhood、Webull、富途牛牛、雪球、支付宝理财等），其面向用户的个股/基金详情页通常包含以下基础功能：

- **价格走势图**：折线图、K线图，支持多时间维度（1日、1周、1月、1年、5年等）。
- **核心报价**：当前价格、涨跌额、涨跌幅、盘前/盘后价格。
- **基础统计数据**：开盘价、最高/最低价、成交量/额、总市值、市盈率(P/E)、股息率等。
- **技术指标**：均线(MA)、MACD、KDJ、布林带(BOLL)等。
- **交易盘口**：买卖十档报价、资金流向。
- **公司/基金基本面**：公司简介、高管信息、基金经理、成立时间、费率等。
- **财务与盈利**：历年营收与净利润、财报日历。
- **分析师评级**：买入/持有/卖出比例、目标价预测。
- **持仓明细（针对基金）**：前十大重仓股/行业分布。
- **资讯与社区**：相关新闻、公告、用户讨论。

## 2. 功能筛选与重组（基于小白友好与可视化原则）

根据“必要性”、“指标易懂性”和“可视化优先”的原则，对上述功能进行大刀阔斧的筛选：

### ❌ 剔除（过于复杂、增加认知负担）

- **K线图与复杂技术指标**：剔除蜡烛图（K线）、MACD、KDJ、布林带等。小白用户只需要知道“趋势向上还是向下”，复杂的指标会引发焦虑。
- **交易盘口（买卖档位）与交易操作**：完全剔除。FirstSpot 不涉及内部交易操作，小白用户不需要看盘口，也不需要底部的买卖按钮。
- **密集的财务表格**：剔除枯燥的资产负债表、现金流量表数字。

### ✅ 保留与视觉化改造（核心功能）

**模块一：极简头部报价与走势（The Hero Section）**

- **当前价格与涨跌幅**：大字号展示，颜色随涨跌变化（红涨绿跌或绿涨红跌，视地区设定，默认国内红涨）。
- **极简折线图（Line Chart）**：只展示收盘价连线。支持交互（长按显示某点价格）。下方提供清晰的时间维度切换（1D, 1W, 1M, 1Y, ALL）。
- **背景/渐变色**：图表下方可带轻微的渐变填充，增强视觉体积感。

**模块二：核心统计卡片（Key Stats）**

- 将密集的数字转化为易读的卡片网格。
- 仅保留最必要的指标：**总市值**（衡量大小）、**市盈率 P/E**（衡量贵贱，可配以“偏高/合理/偏低”的文字标签）、**股息率**（衡量分红）、**最高/最低价**（通过一个进度条展示当前价格在52周内的位置）。

**模块三：分析师评级与情绪（Analyst Ratings - 极度易懂）**

- **可视化表达**：使用一个类似“汽车仪表盘”或“红绿灯”的半圆环，指针指向“强力买入”、“持有”或“卖出”。
- **比例条**：展示多少百分比的分析师建议买入，直观反映市场情绪。

**模块四：财务健康度（Financial Health - 图像化）**

- **可视化表达**：使用简单的柱状图（Bar Chart）对比过去4个季度的“营业收入”与“净利润”。
- 避免复杂的财务术语，直接用“赚了多少钱（营收）”和“实际落袋多少（净利润）”的概念。

**模块五：公司/基金名片（About）**

- 一段简短的白话文介绍（可由AI生成总结，不超过3行）。
- 标签化展示所属行业（如：#新能源、#科技）。
- 若为基金，使用饼图（Pie Chart）展示其“行业分布”或“前五大重仓股”的Logo与占比。

## 3. 页面结构与交互流设计

从上到下的滚动页面结构：

1. **Top Bar**: 返回按钮，股票代码/名称，收藏(Star)按钮。
2. **Hero Area**:
  - 巨大且清晰的当前价格。
  - 涨跌幅（带箭头）。
  - 占据屏幕宽度100%的平滑折线图。
  - 时间选择器（胶囊按钮样式）。
3. **Stats Grid**: 2x2 或 2x3 的小卡片，展示市值、P/E、52周范围（带进度条）。
4. **Divider/Section**: 分析师情绪仪表盘。
5. **Divider/Section**: 财务柱状图（营收 vs 利润）。
6. **Divider/Section**: 关于公司（简介文本 + 行业标签）。
7. **Bottom Myo Companion**: 页面最下方放置 Myo 角色的微笑陪伴插画（不涉及内部交易操作，不设买卖按钮，保持纯粹的信息/教育属性）。

## 4. Figma 原型设计指引

- **色彩规范**：背景使用干净的白色/深色模式极黑。涨跌色需统一（国内红涨绿跌，或国际绿涨红跌，建议在设置中可调，原型先以**绿色代表上涨/积极，红色代表下跌/消极**的国际通用版或Robinhood风格为例，显得更现代）。
- **排版**：大量留白（Whitespace），大圆角（Radius 16px+），去除不必要的边框线，用轻微的阴影或背景色块区分层级。
- **图表**：折线图线条要使用单调三次插值（Monotone Cubic Interpolation）绘制成平滑的曲线，以防止在价格剧烈波动时出现超出极值的“过冲（Overshooting）”现象，不要有网格线干扰。
- **多窗口一致性**：1D / 1W / 1M / 3M / 1Y / ALL 只改变时间范围，不改变视觉语言。长周期窗口需要先做显示用降采样，再交给平滑折线绘制，避免 ALL / 1Y 因原始点过密出现锯齿化折线；短周期窗口保留原始收盘价点。
