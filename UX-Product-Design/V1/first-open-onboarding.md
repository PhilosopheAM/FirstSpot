## UX-Product-Design / V1：首次打开投资者教育流程

### 1. 产品背景 & 目标用户

- **产品定位**  
  - 投资账本 + 投资者教育 App  
  - 帮助年轻人把工资 / 零花钱从「花掉」变成「攒下 → 投入稳健资产」

- **一句话记忆点**  
  - **为年轻人攒下第一桶金**

- **目标用户画像（首要人群）**  
  - **年龄**：18–30 岁  
  - **身份**：在校学生（用零花钱 / 奖学金尝试投资）、刚步入职场的普通白领  
  - **投资水平**：  
    - 完全没接触过、对投资抱警惕的小白  
    - 已经尝试股票，但对市场缺乏基本认知，希望从「追涨杀跌散户」转向「更稳健的长线投资者」  
  - **风险偏好**：  
    - 特别怕亏钱  
    - 或接受小幅波动，但不接受「爆仓式」风险

- **本版本关注的唯一场景**  
  - 用户**第一次打开 App**时，体验「最基本交易概念」的投资者教育流程。

- **本版本核心目标（优先级从高到低）**  
  1. 让用户觉得「每月把一点钱变成资产」是**可控、可学会的事情**  
  2. 建立对 App 的**信任感**：不荐股、不带杠杆、以长期陪伴为主  
  3. 为后续「新手村式教育任务」埋下入口和期望

- **情绪基调**  
  - 像**游戏新手村**：有向导、有任务、有轻松氛围  
  - 视觉多彩可爱，但内容强调稳健和理性

---

### 2. 核心使用场景 / 用户路径（首次打开）

- **场景：首次打开 App → 完成第一段教育体验 → 落地首页新手任务**

- **用户路径（高层级）**
  1. 打开 App（可免注册轻体验）  
  2. `Onboarding_01_Welcome`：新手村欢迎 + 安全承诺 + 「进入新手村」  
  3. `Onboarding_02_Profile_Lite`：通过 2–3 个选择题，了解用户的资金与心态  
  4. `Onboarding_03_Mini_Lesson`：用迷你互动教程解释 3 个基础概念：本金 / 涨跌 / 盈亏  
  5. `Onboarding_04_Starter_Plan`：为用户生成一个极小的「起步计划」  
  6. `Home_01_Dashboard`：落入首页，显示「今日新手任务」卡片，承接后续教育流程

---

### 3. 页面列表（画板命名建议）

- **Onboarding_01_Welcome**  
  - 作用：欢迎新用户、定调「第一桶金」和「稳健投资」，引导进入新手村任务。

- **Onboarding_02_Profile_Lite**  
  - 作用：轻量化收集用户身份、每月可攒金额、对波动的情绪反应。

- **Onboarding_03_Mini_Lesson**  
  - 作用：通过 3 个小关卡解释：本金、涨跌、盈亏。

- **Onboarding_04_Starter_Plan**  
  - 作用：基于用户输入生成极小的起步目标 + 安全承诺。

- **Home_01_Dashboard**  
  - 作用：展示「今日新手任务」和「我的小金库」入口，承接日常使用。

---

### 4. 关键页面摘要

#### 4.1 Onboarding_01_Welcome（新手村欢迎页）

- **信息优先级**
  1. 标题：为年轻人攒下第一桶金  
  2. 副标题：不荐股、不带杠杆，只教你看懂钱的游戏规则  
  3. 理财向导形象（插画 / 卡通角色）  
  4. 主按钮：进入新手村  
  5. 次级动作：稍后再说（跳过）

- **主要交互**
  - 点击主按钮 → 进入 `Onboarding_02_Profile_Lite`。  
  - 点击「稍后再说」→ 可直接进入 `Home_01_Dashboard`（无新手教程）。

- **设计考量**
  - 第一屏即说明「不搞投机，只教知识」以降低防御心。  
  - 用游戏新手村 + 多彩插画减轻金融场景的严肃和恐惧感。

#### 4.2 Onboarding_02_Profile_Lite（轻量自我画像）

- **信息优先级**
  1. 标题：先聊聊你的第一桶金，从哪来？  
  2. 三组选择题：身份 / 每月可攒金额 / 面对波动的情绪  
  3. 顶部步骤指示：步骤 1/3  
  4. 下一步按钮

- **主要交互**
  - 所有问题为单选 / 多选按钮，无自由输入。  
  - 每完成一个问题，向导给一句简短反馈。  
  - 点击下一步 → 进入 `Onboarding_03_Mini_Lesson`。

- **设计考量**
  - 实质上是超简风险测评 + 现金流问卷，但呈现为轻松聊天。  
  - 结果用于后续个性化起步计划与示例数字。

### 5. 关键界面元素清单（给设计师画线框）

#### 5.1 Onboarding_01_Welcome 元素清单

- **整体布局（竖屏移动端）**
  - 顶部系统状态栏占位。

- **顶部区域**
  - 右上角小号文字按钮：`跳过` / `稍后再说`  
    - 视觉弱化（灰色或次级色、小字号）。

- **中上区域：标题 & 文案**
  - 主标题（大号）：  
    - 文案示例：**为年轻人攒下第一桶金**。  
  - 副标题（2 行以内，中等字号）：  
    - 关键点：不荐股、不带杠杆、教规则不赌短线。  
    - 示例：  
      - “不荐股、不加杠杆，只陪你一起学会看懂钱的游戏规则。”

- **中间主视觉区域**
  - 插画 / 卡通角色区域：  
    - 角色：理财向导（可爱、多彩，非金融机构 Logo）。  
    - 姿态：欢迎 / 引导姿势（如挥手 / 递出金币罐）。  
  - 插画下方可选一行补充文案：  
    - “就当是一款有任务的新手村游戏，从这里开始。”

- **底部 CTA 区域**
  - 主按钮（全宽，显眼，圆角）：  
    - 文案：**进入新手村** 或 **开始新手任务**。  
  - 次级说明文字（按钮下方，小字号）：  
    - 示例：“后续可以随时在设置里退出新手村模式。”（可选）。

- **背景与风格**
  - 背景：浅色 / 渐变，多彩但不刺眼。  
  - 整体风格：圆角、柔和阴影，符合游戏新手村 + 可爱风。

---

#### 5.2 Onboarding_02_Profile_Lite 元素清单

- **整体布局（竖屏移动端）**
  - 顶部状态栏占位。

- **顶部区域**
  - 返回箭头（可选，决定是否允许回退到欢迎页）。  
  - 中央标题（导航栏或内容区第一行）：  
    - 文案：**先聊聊你的第一桶金，从哪来？**  
  - 顶部进度指示：  
    - 形式：进度条或分段 Step Indicator。  
    - 文案示例：`步骤 1/3`。

- **中部内容区域：三块问题模块（纵向排列）**

  - **问题 1：身份**
    - 问题标题：  
      - “你现在主要的身份是？”  
    - 选项列表（按钮 / 卡片式）：  
      - 在校学生  
      - 刚工作（1–3 年）  
      - 工作 3 年以上  
      - 其它  
    - 选中态：高亮背景 + 勾选标记。

  - **问题 2：每月大概能攒下多少钱？**
    - 问题标题：  
      - “大概每月能攒下多少钱？”  
    - 选项形式：按钮组 / 标签云 / 单选卡片：  
      - `<200` 元  
      - `200–500` 元  
      - `500–1000` 元  
      - `>1000` 元  
    - 下方一行引导文案（灰色小字）：  
      - “不用太精确，一个大概范围就好。”

  - **问题 3：看到账户波动时的感受**
    - 问题标题：  
      - “看到账户有涨有跌时，你更像是哪种？”  
    - 选项以表情 + 文案形式呈现（横向卡片或纵向列表）：  
      - 选项 A：表情 😰 + “一点点亏就睡不着”  
      - 选项 B：表情 🙂 + “小起伏还能接受”  
      - 选项 C：表情 😎 + “能接受上下波动，但不想爆仓那种”

- **轻反馈区域（与问题联动）**
  - 一行小型提示气泡，左侧是理财向导小头像：  
    - 用户选 `<200 元`：  
      - “很多人也是从每月 200 开始的，关键是坚持。”  
    - 用户选“怕亏钱”：  
      - “怕亏钱是正常的，我们会从最基础的安全感开始讲。”

- **底部 CTA 区域**
  - 主按钮（全宽）：  
    - 文案示例：**下一步：看看投资到底在干嘛**。  
    - 点击条件：至少完成设定的必答问题。  
  - 未填完必答题时：  
    - 按钮置灰。  
    - 上方可有提示文案：  
      - “再回答上面的问题，我就能给你更合适的起步建议。”

- **其他状态 & 适配**
  - 键盘弹出时保证按钮可见（按钮可固定在底部）。  
  - 小屏设备时，注意控制每个选项文案长度在 1 行内。
