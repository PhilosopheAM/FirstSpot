## Onboarding_01_Welcome（新手村欢迎页）

- **信息优先级**
  1. 标题：为年轻人攒下第一桶金  
  2. 副标题：不荐股、不带杠杆，只教你看懂钱的游戏规则  
  3. 理财向导形象（插画 / 卡通角色）  
  4. 主按钮：进入新手村  
  5. 次级动作：稍后再说（跳过）

- **主要交互**
  - 点击主按钮 → 进入 `Onboarding_02_Profile_Lite`。  
  - 点击「稍后再说」→ 可直接进入 `Home_01_Dashboard`（无新手教程）。

- **设计考量**
  - 第一屏即说明「不搞投机，只教知识」以降低防御心。  
  - 用游戏新手村 + 多彩插画减轻金融场景的严肃和恐惧感。

### Onboarding_01_Welcome 元素清单

- **整体布局（竖屏移动端）**
  - 顶部系统状态栏占位。

- **顶部区域**
  - 右上角小号文字按钮：`跳过` / `稍后再说`  
    - 视觉弱化（灰色或次级色、小字号）。

- **中上区域：标题 & 文案**
  - 主标题（大号）：  
    - 文案示例：**为年轻人攒下第一桶金**。  
  - 副标题（2 行以内，中等字号）：  
    - 关键点：不荐股、不带杠杆、教规则不赌短线。  
    - 示例：  
      - “不荐股、不加杠杆，只陪你一起学会看懂钱的游戏规则。”

- **中间主视觉区域**
  - 插画 / 卡通角色区域：  
    - 角色：理财向导（可爱、多彩，非金融机构 Logo）。  
    - 姿态：欢迎 / 引导姿势（如挥手 / 递出金币罐）。  
  - 插画下方可选一行补充文案：  
    - “就当是一款有任务的新手村游戏，从这里开始。”

- **底部 CTA 区域**
  - 主按钮（全宽，显眼，圆角）：  
    - 文案：**进入新手村** 或 **开始新手任务**。  
  - 次级说明文字（按钮下方，小字号）：  
    - 示例：“后续可以随时在设置里退出新手村模式。”（可选）。

- **背景与风格**
  - 背景：浅色 / 渐变，多彩但不刺眼。  
  - 整体风格：圆角、柔和阴影，符合游戏新手村 + 可爱风。
