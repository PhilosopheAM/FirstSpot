## Onboarding_02_Profile_Lite（轻量自我画像）

- **信息优先级**
  1. 标题：先聊聊你的第一桶金，从哪来？  
  2. 三组选择题：身份 / 每月可攒金额 / 面对波动的情绪  
  3. 顶部步骤指示：步骤 1/3  
  4. 下一步按钮

- **主要交互**
  - 所有问题为单选 / 多选按钮，无自由输入。  
  - 每完成一个问题，向导给一句简短反馈。  
  - 点击下一步 → 进入 `Onboarding_03_Mini_Lesson`。

- **设计考量**
  - 实质上是超简风险测评 + 现金流问卷，但呈现为轻松聊天。  
  - 结果用于后续个性化起步计划与示例数字。

---

### Onboarding_02_Profile_Lite 元素清单

- **整体布局（竖屏移动端）**
  - 顶部状态栏占位。

- **顶部区域**
  - 返回箭头（可选，决定是否允许回退到欢迎页）。  
  - 中央标题（导航栏或内容区第一行）：  
    - 文案：**先聊聊你的第一桶金，从哪来？**  
  - 顶部进度指示：  
    - 形式：进度条或分段 Step Indicator。  
    - 文案示例：`步骤 1/3`。

- **中部内容区域：三块问题模块（纵向排列）**

  - **问题 1：身份**
    - 问题标题：  
      - “你现在主要的身份是？”  
    - 选项列表（按钮 / 卡片式）：  
      - 在校学生  
      - 刚工作（1–3 年）  
      - 工作 3 年以上  
      - 其它  
    - 选中态：高亮背景 + 勾选标记。

  - **问题 2：每月大概能攒下多少钱？**
    - 问题标题：  
      - “大概每月能攒下多少钱？”  
    - 选项形式：按钮组 / 标签云 / 单选卡片：  
      - `<200` 元  
      - `200–500` 元  
      - `500–1000` 元  
      - `>1000` 元  
    - 下方一行引导文案（灰色小字）：  
      - “不用太精确，一个大概范围就好。”

  - **问题 3：看到账户波动时的感受**
    - 问题标题：  
      - “看到账户有涨有跌时，你更像是哪种？”  
    - 选项以表情 + 文案形式呈现（横向卡片或纵向列表）：  
      - 选项 A：表情 😰 + “一点点亏就睡不着”  
      - 选项 B：表情 🙂 + “小起伏还能接受”  
      - 选项 C：表情 😎 + “能接受上下波动，但不想爆仓那种”

- **轻反馈区域（与问题联动）**
  - 一行小型提示气泡，左侧是理财向导小头像：  
    - 用户选 `<200 元`：  
      - “很多人也是从每月 200 开始的，关键是坚持。”  
    - 用户选“怕亏钱”：  
      - “怕亏钱是正常的，我们会从最基础的安全感开始讲。”

- **底部 CTA 区域**
  - 主按钮（全宽）：  
    - 文案示例：**下一步：看看投资到底在干嘛**。  
    - 点击条件：至少完成设定的必答问题。  
  - 未填完必答题时：  
    - 按钮置灰。  
    - 上方可有提示文案：  
      - “再回答上面的问题，我就能给你更合适的起步建议。”

- **其他状态 & 适配**
  - 键盘弹出时保证按钮可见（按钮可固定在底部）。  
  - 小屏设备时，注意控制每个选项文案长度在 1 行内。
