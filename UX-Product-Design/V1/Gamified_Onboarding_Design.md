## 1. 设计目标与关键成功指标

### 1.1 本版本单一目标

**让一个偶然下载 FirstSpot 的 Z 世代用户，在第一次打开后的 7 天内形成「每天打开一次」的习惯。**

所有游戏化机制都服务于这一目标，不为了炫技而加机制。

### 1.2 北极星指标（North Star Metric）

- **D7 连续打开率（D7 Streak Rate）**：首次打开后第 7 天仍然打开 App 的用户占比。
- **目标值**：V1 上线 30 天后不低于 **28%**（高于同类金融教育 App 行业均值约 10%）。

### 1.3 支撑指标（按重要性排序）


| 指标                 | 解释                      | V1 目标           |
| ------------------ | ----------------------- | --------------- |
| D1/D3/D7 Retention | 首开次日 / 第 3 天 / 第 7 天回访率 | 65% / 42% / 28% |
| Onboarding 完成率     | 首开 4 步 + 首章流程全部走完       | ≥ 70%           |
| 首章小测通过率            | `CARD-01` 发放成功率         | ≥ 85%           |
| Daily XP 达标率       | 每日完成 1 次学习拿到 ≥ 10 XP    | ≥ 50%（活跃用户）     |
| Streak≥7 占比        | 连续打卡 7 天及以上的用户占 MAU     | ≥ 15%           |
| 推送 CTR             | 游戏化文案推送的点击率             | ≥ 12%（行业均值约 4%） |


### 1.4 反指标（明确不追求）

- **不追求**日均停留时长过长（>30 分钟）——投资教育不同于语言学习，过度沉迷反而违背"稳健"定位。
- **不追求**短期付费转化（V1 无付费机制）。

## 2. 目标用户画像（Z 世代专属洞察）

### 2.1 年龄分层


| 细分                | 年龄    | 身份         | 主要痛点                        |
| ----------------- | ----- | ---------- | --------------------------- |
| Z 早期（Gen Z Early） | 16–20 | 高中生 / 大一新生 | 零花钱/奖学金想理财但听不懂术语，被"理财诈骗"吓怕  |
| Z 中期（Gen Z Mid）   | 21–24 | 大学生 / 准毕业生 | 实习工资想攒钱，朋友圈开始出现"攒钱博主"焦虑     |
| Z 后期（Gen Z Late）  | 25–28 | 初入职场白领     | 有首份薪资但被房租/通勤吃掉，怕自己"三十岁还没存款" |


### 2.2 Gen Z 行为与审美特征（影响设计决策）

- **短内容原生（Short-Form Native）**：抖音/B 站的 15 秒节奏内化到注意力阈值；任何页面首屏超过 3 秒没有反馈就会被划走。
- **梗文化（Meme Fluency）**：文案不能端着，适当自嘲 > 端庄说教；"上岸""发疯""躺平"等梗词可谨慎植入但**不可喧宾夺主**。
- **反消费主义倾向**：讨厌被当韭菜，对"高收益"和"赚快钱"话术高度警惕 → 正好契合 FirstSpot"不荐股不杠杆"的品牌承诺。
- **视觉风格**：Y2K 复古 + Neo-Brutalism 粗犷边框 + 多彩渐变并存，但**偏爱高饱和 + 克制**而非花哨。
- **社交压力**：愿意晒"有意思的"东西到小红书 / 朋友圈 / 微信群；**可截图炫耀的里程碑**是最高效的增长引擎。
- **FOMO vs 焦虑排斥**：既怕错过又怕被制造焦虑；**推送文案必须「有趣」而非「紧张」**。
- **身份表达**：把 App 的头像 / 徽章 / 收藏当作「我是什么样的人」的符号。

### 2.3 情绪基调（Brand Voice）

- **像一只懂事的朋友**，而不是像爸妈或理财老师。
- **多邻国式腹黑幽默**可借鉴，但**不能冒犯**——理财话题一旦触发"被嘲笑没钱"的情绪会直接卸载。
- **用"我们"而不是"你"**：强调陪伴感。
- **永不说**：
  - "翻倍" / "暴涨" / "财富自由" / "抄底"
  - "投资稳赚" / "保本高收益"
  - 任何鸡汤体（"努力就会成功"之类）

## 3. 游戏化设计哲学（5 条核心法则）

> 写在所有机制之前的「不准违背」红线。

### 法则 1：**每 15 秒必须给一次反馈**

从点击按钮到学完一章，任何动作后 15 秒内必须有视觉 / 听觉 / 触觉的正向反馈（哪怕只是向导猫眨眼）。参考多邻国"每答对一题就有音效 + XP 小数字飘出"。

### 法则 2：**奖励前置，代价延后**

先给用户看"完成后能得到什么"（卡片预览 / 经验值预告 / 向导猫表情预告），再让他做事。**永远不先罚再赏**。

### 法则 3：**失败不能有真实惩罚**

小测答错不扣卡、不扣钱、不锁关卡——**最多只扣"心（Lives）"这种可以自动恢复的象征性资源**。Z 世代对"扣钱扣进度"极度敏感，一次负反馈可能永久流失。

### 法则 4：**所有机制必须与"稳健投资"品牌承诺不冲突**

不能出现"连抽卡"、"转盘"、"限时秒杀"这类**与短线投机心理同构**的机制。FirstSpot 的游戏化应该让人感到**"慢慢变好"**，而不是"一夜暴富"。

### 法则 5：**永远可以「今天不玩」**

推送不威胁（不说"你的 streak 要没了，快回来！"这种绑架式文案），提供「Streak Freeze（护盾）」或「保底机制」兜底。让用户觉得 **"我在掌控这段关系"** 而不是被 App 绑架。

## 4. 核心游戏化系统（10 大机制）

本节是**机制目录**，每个机制包含：定义 / Duolingo 对标 / FirstSpot 本土化 / 视觉符号 / 数值参数。

### 4.1 IP 角色系统：向导猫 **Myo（喵）**

- **定位**：FirstSpot 的「多邻国猫头鹰 Duo」。
- **命名由来**：
  - 中文名 **「喵」**，取自猫叫声，一个字，好记、好呼叫、自带年轻化亲昵感（类似"嘛酱""咕卡"那种叠词口吻）。
  - 英文名 **Myo**（/miːoʊ/），是 Meow 的简写变体，国际化版本发音一致、拼写更短，易做 LOGO 字体设计。
  - 语感上接近 "my own"（我自己的）—— 暗含陪伴感与「属于你自己的投资向导」。
- **形象来源**：复用项目已有素材 `创意参考图/线条小猫v1-跟我来.png`（线条猫插画），重新升级为**多彩线条 + 可爱圆润**的 IP 猫。
- **人格设定**：
  - 15 岁、不懂装懂但爱学习的一只小猫
  - 跟用户**平视**（不是高高在上的导师），一起摸索
  - 爱吃罐头（金币图标灵感来源）、讨厌烟雾（骗局/炒股号提示时变愤怒）
- **表情库（至少 12 套，用于不同场景）**：
  - 默认微笑、眨眼、欢呼、鼓掌、托腮思考、偷偷瞄、装死躺平、流泪、愤怒（见骗局时）、睡觉（7 天未打开时）、戴墨镜（完成金卡章节时）、戴生日帽（纪念日）
- **出现位置**：
  - 欢迎页（C 位）
  - 每道题旁的反馈气泡（左下角小头像）
  - 连续打卡里程碑（全身动画）
  - 推送消息头像
  - 首页顶部"今日陪伴"卡片
- **资源位**：`Design_Resource/UI_design_resource/characters/myo/*.png|.riv`
  - 推荐使用 **Rive 动画**（比 Lottie 更轻量 + 可互动），让 Myo 能响应点击（被戳会真的喵一声）。（注：目前已用 Flutter 动画实现）

### 4.2 XP 经验值 & 等级系统

- **命名**：**第一桶金经验值（First-Pot XP / FP-XP）**
- **Duolingo 对标**：XP + 等级（Level 1~25）
- **FP-XP 获取**（每个动作都明码标价）：


| 动作         | FP-XP         |
| ---------- | ------------- |
| 首开 4 步引导完成 | +50           |
| 每日首次打开 App | +5            |
| 小测答对 1 题   | +2            |
| 完成 1 章概念讲解 | +10           |
| 通过章末小测（首次） | +30           |
| 获得概念卡（首次）  | +20           |
| 分享卡片到社交    | +10（每日上限 1 次） |
| 连续打卡 7 天   | +50 奖励        |
| 连续打卡 30 天  | +200 奖励       |


- **等级划分（10 级制，对应投资者成长阶段）**：


| 等级    | 称号         | 累计 FP-XP | 解锁          |
| ----- | ---------- | -------- | ----------- |
| Lv.1  | 观望的萌新      | 0        | 基础功能        |
| Lv.2  | 踮脚看市场      | 100      | 首页自定义壁纸     |
| Lv.3  | 第一次点开 K 线  | 250      | Myo 新表情 × 3 |
| Lv.4  | 懂什么叫 PE 的人 | 500      | 暗色模式        |
| Lv.5  | 风险三兄弟的朋友   | 900      | 周报生成权限      |
| Lv.6  | 一篮子的信徒     | 1400     | 主题皮肤选择器     |
| Lv.7  | 压舱石搭建者     | 2000     | 自定义 Myo 配饰  |
| Lv.8  | 纪律的化身      | 2800     | 榜单匿名头衔      |
| Lv.9  | 时间的朋友      | 3800     | 金色闪光边框      |
| Lv.10 | 拥有自己系统的人   | 5000     | 「V2 进阶」预约通道 |


- **设计要点**：
  - 升级时 **全屏烟花 + Myo 戴新帽子 + 触感震动**。
  - 等级与"投资水平"弱耦合——避免暗示用户"升级=更会炒股"（这违背品牌承诺）。等级更多是**学习里程碑**。

### 4.3 连续打卡 Streak（**核心留存引擎**）

- **Duolingo 对标**：Duolingo 近五年用户留存的第一大功臣。FirstSpot 完全继承这套机制。
- **规则**：
  - 每日完成任意一个学习动作（打开 1 章 / 答对 1 题 / 完成 1 次记账）即 +1 天 streak
  - 连续 2 天没完成则归零
- **Streak Freeze（冰冻护盾）**：
  - 开通后自动在"断卡当天"为你顶上，避免归零
  - 每人默认赠送 **2 个**，之后每周一领 1 个（免费，不搞付费）
  - 最多持有 3 个（避免失去紧迫感）
- **视觉符号**：
  - 主图标：🔥（火焰），数值显示在顶部栏
  - Streak ≥ 7：火焰变蓝
  - Streak ≥ 30：火焰变紫
  - Streak ≥ 100：火焰变金 + 粒子特效
  - Streak ≥ 365：Myo 穿上「陪你一年」披风
- **里程碑（带全屏庆祝动画）**：
  - 3 天：小火苗 + "你居然回来了！"
  - 7 天：蓝焰 + 自动解锁一张「彩蛋表情包」（可分享到小红书）
  - 14 天：Myo 戴毕业帽 + 生成个人战报海报
  - 30 天：紫焰 + 解锁一张 **稀有限定头像框**
  - 100 天：金焰 + 获得「百日不倒翁」成就徽章
  - 365 天：**全年第一桶金**成就 + Myo 全家福
- **Streak Repair（复活）**：
  - 第一次断卡后 48 小时内可以**免费**复活一次（前 30 天内）
  - 之后的复活需要 **200 金币**（见 4.5）
  - **不卖复活道具现金付费**——避免让人觉得"花钱买后悔药"，违背稳健价值观

### 4.4 心 Lives（耐心值）

- **Duolingo 对标**：每错 1 题扣 1 颗心，掉光后要等回复或看广告。
- **FirstSpot 本土化**：**改名为「耐心值」**，共 5 颗。
- **规则**：
  - 每章小测答错 1 题扣 1 颗耐心
  - 掉到 0 时，**当天**不能继续刷小测（但可继续看内容、做记账、刷收藏橱窗，不影响核心学习）
  - **每 2 小时**自动恢复 1 颗（比多邻国的 5 小时更友好，防止流失）
  - 看 1 段 20 秒的「Myo 冷知识视频」可恢复 1 颗（相当于软广/品牌曝光）
- **为什么选"耐心值"而不是"心"**：
  - "心" 在投资场景下容易被联想到"本金亏损"，触发负面情绪
  - "耐心" 本身就是投资长期主义要培养的素质——机制与内容价值观同构
- **视觉**：顶部栏 5 颗小爱心 / 沙漏，掉光时变成灰色 + Myo 躺平表情。

### 4.5 双货币系统：**金币 & 宝石**

- **金币（Coins，🪙）**：普通货币，获取容易，消耗场景多。
- **宝石（Gems，💎）**：稀有货币，仅通过重大里程碑获得，用于特殊兑换。


| 货币    | 获取                               | 消耗                                               |
| ----- | -------------------------------- | ------------------------------------------------ |
| 🪙 金币 | 每日任务 +10、小测满分 +20、章节完成 +50       | 买 Streak Freeze（200）、复活断卡（200）、买 Myo 衣服（100–500） |
| 💎 宝石 | 等级升级 +1、章节金卡 +3、100 天 streak +10 | 兑换限定头像框、参加周榜保级券                                  |


- **设计红线**：
  - **不做抽卡 / 盲盒 / 开箱**（与投机心理同构）
  - **不做现金换金币**（V1 完全无 IAP）
  - **不做金币兑换真钱或优惠券**（避免"赚钱化"误导，违背监管）
  - 金币的最大价值是**装饰性 / 情感性**（换 Myo 的衣服、换壁纸），不影响核心学习

### 4.6 关卡路径（Learning Path）

- **Duolingo 对标**：蛇形学习路径 Tree / Path。
- **FirstSpot 形态**：**「小金库成长路径」** —— 一条从"种子"到"大树"的视觉隐喻路径。
  - 12 个章节 = 12 个路径节点
  - 每节点是一颗种子 🌱 → 嫩芽 → 小树 → 果树
  - 章节完成时节点"开花结果"，掉下一张概念卡（CARD-0x）
- **视觉布局**：
  - **纵向滚动的 S 形路径**（参考 Duolingo 2022 年改版后的 Path）
  - 当前可学章节**轻微弹跳 + 光圈**吸引眼球
  - 已完成章节显示**卡片稀有度颜色**（白/蓝/紫/金）
  - 未解锁章节**轻微灰度 + 锁图标**
- **跳章规则（重要）**：
  - **允许**有金融基础的用户**跳章**（小测 5/5 正确直接通关）
  - 但**不允许**跳过第 1 章和第 12 章——二者是品牌承诺的"开场白"和"毕业典礼"
- **分支（V1 暂不实现，V2 规划）**：
  - 完成第 6 章后可选"深度派"或"佛系派"两条支线
  - 深度派：额外解锁财报精读小章
  - 佛系派：聚焦定投+ETF

### 4.7 联盟排行榜（**Weekly League**）

- **Duolingo 对标**：青铜/白银/黄金/钻石/黑曜石 联盟，每周重置。
- **FirstSpot 本土化**：**「成长小组」** —— 每周 30 人一组，按本周 FP-XP 排名。
- **晋升规则**：
  - 每周周日 24:00 结算
  - 前 10 名晋级下一联盟
  - 11–20 名留在当前联盟
  - 21–30 名掉回上一联盟（**首次不掉**，给新手保护期）
- **联盟序列**（金融化命名）：
  1. 储蓄罐联盟（Bronze 对应）
  2. 银行卡联盟（Silver）
  3. 基金联盟（Gold）
  4. 指数联盟（Sapphire）
  5. 价值投资联盟（Ruby）
  6. 第一桶金联盟（Emerald）
  7. 时间的朋友联盟（Amethyst）
  8. 巴菲特午餐联盟（Diamond，最高）
- **设计要点**：
  - **默认匿名头衔** + 可选 emoji 头像（不强求真实身份，避免攀比压力）
  - **排行榜不显示具体学习内容**（别人不知道你"这周在学风险章"，保护隐私）
  - **上升通道不绑定付费**——任何人靠努力都能升
- **伦理红线**：
  - 排行榜**只比学习 XP**，**绝不比投资收益率**（FirstSpot 不是炒股排位赛）
  - 不显示"击败全国 xx%" —— 避免焦虑

### 4.8 成就徽章系统

- **形式**：收藏册里的印章，永久保留。
- **分类**：


| 类别  | 示例                                           | 稀有度      |
| --- | -------------------------------------------- | -------- |
| 连续类 | 7 日连击 / 30 日连击 / 百日不倒翁 / 365 全年陪伴            | 蓝/紫/金/传说 |
| 学习类 | 初窥门径（完成 01 章）/ 稳健信徒（完成 08 章）/ 毕业生（完成 12 章）   | 白/紫/金    |
| 行为类 | 早起鸟（早 8 点前打开）/ 夜猫子（晚 11 点后学习）/ 铁人三项（一天看 3 章） | 蓝/蓝/紫    |
| 社交类 | 分享一次 / 一周分享 3 次                              | 白/蓝      |
| 彩蛋类 | 首次遇到骗局识别题答对 / 连续 5 次全对不失血 / Myo 被戳 100 次     | 紫/金/紫    |

### 6.4 `Onboarding_03_Mini_Lesson`（游戏化重构 · 农事四季类比）

> 三关统一用 **「春天播种 → 田里生长 → 秋天收成」** 一条故事线讲清 **本金 / 涨跌 / 盈亏**，避免抽象金融词吓跑新手。每关 **1 道主互动** + **Myo 口吻显性类比讲解** + **耐心值 + XP**。

- **目的**：约 90 秒内让用户「动手 + 听懂类比」，并第一次拿到 XP 反馈。
- **整体布局**：
  - 顶部：**耐心值（5 颗爱心）** + **FP-XP 计数器** + **关卡进度 1/3**
  - 中部上：**Myo 讲解条**（浅绿气泡，1～2 句大白话，可随关卡切换）
  - 中部：**互动主舞台**（拖拽区 / 折线图 / 收成筐）
  - 底部：**无全局下一步**（通关条件满足后自动过渡；答错可重试，不推进关卡）

#### 6.4.1 关卡 1：本金 = 闲置资金 = 春天的种子（拖拽）

- **类比（显性文案，Myo 口吻）**：
  - 「**本金**就是你暂时不急着花掉、愿意拿来『试一试』的那笔钱——我管它叫 **闲置资金**。」
  - 「春天不会凭空长出庄稼——得先把 **种子** 放进土里。**本金就是那颗种子**。」
- **主交互**：屏幕上方一排 **3 枚「闲置资金」硬币**（🪙），下方一块 **「春天·田地」** 虚线框（`DragTarget`）。用户把硬币 **拖进田里** 才算「播种」。
- **动效与触感**：
  - 硬币 `Draggable`：`feedback` 为略放大 + 阴影的硬币；`childWhenDragging` 原位置半透明占位。
  - 拖拽物进入田地：`DragTarget` 边框 **0.2s** 由灰变 **嫩芽绿描边 + 内阴影 pulse**（`AnimatedContainer`）。
  - 松手落入成功：`HapticFeedback.lightImpact` + 硬币在田内 **scale 0.85→1.0 spring** + 变为 🌱 小芽图标（短动画 300ms）。
  - 尚未播种时误点田地：轻微 **shake**（`translate` ±4px，120ms）+ Myo 一句「先拖一枚硬币进来嘛～」。
- **通过条件**：**至少播种 1 枚**（与「有本金才能谈后面」一致）；三枚全种可选彩蛋文案。
- **Myo 实时反馈（播种后）**：
  - 1 枚：「好耶，有种子就有故事开头了——这是稳稳的第一步～」
  - 3 枚：「哇，三颗都下地了！大方，但记得：**只用闲钱** 哦。」
- **奖励**：+2 XP（飘字，见 6.4.4）

#### 6.4.2 关卡 2：涨跌 = 种子能否健康生长；田地 = 市场与标的物（折线 + 三选一）

- **类比（显性文案）**：
  - 「上一关我们把 **闲置资金** 种进了田。**涨跌**不是让你猜明天天气——是在看：这颗种子在 **这块田里**，这段时间 **长得健不健康、长势往上还是往下**。」
  - 「这块 **田地**，在现实里就是 **你选择的市场和标的物**（比如某只指数基金、某条指数）——不同田，土质不一样，长势也不一样。」
- **主视觉**：保留 **30 天折线图**（`fl_chart`）；**图下小字**：「纵轴可以理解为『长势评分』，折线整体向上 = 这段时间里，**在田里长得更好**。」
- **提问**：「看这条线，从春天到第 30 天，整体是 **长好了**、**差不多**、还是 **没长好（跌）**？」三键：**长好了（涨）** / **差不多（横盘）** / **没长好（跌）**（文案避免纯箭头符号，降低误解）。
- **动效与触感（按键）**：
  - 按下：`BouncyButton` 已有 **下沉**；外层再包 `**AnimatedScale` 0.97 → 1.0**（150ms，`Curves.easeOutCubic`）。
  - 选中：按钮边框 **2px 嫩芽绿** + 背景浅绿 **150ms**；未选项 **0.1s opacity 0.55**（非禁用，仅视觉弱化）。
  - 判定正确：`HapticFeedback.mediumImpact` + 折线图底部 **一道浅绿 sweep**（300ms）可选。
- **答错**：扣 1 耐心 + `HapticFeedback.heavyImpact`（或 `vibrate` 轻档）+ Myo：「没关系啦，很多人第一遍也会看错——**涨跌看的是『长势』，不是猜运气**。」**0.6s 后清除选中态**，允许再选（不推进关卡）。
- **答对**：+2 XP + Myo：「对啦！这条线整体往上，说明在这段时间里，**种子在这块田里长得更好了**。」

#### 6.4.3 关卡 3：盈亏 = 秋天收成 = 多因素共同作用的结果（emoji 拖入收成筐）

- **类比（显性文案）**：
  - 「到 **秋天** 才有收成。**盈亏**就是：秋天粮仓里，**多收还是少收**。」
  - 「收成好不好，不只看春天种了几颗——还有雨水、虫害、你有没有除草……对应投资里，就是 **时间、市场、标的、运气和纪律** 一堆因素加在一起的结果。」
- **主交互**：文案区给出本关场景：「春天你准备了 100 颗种子，秋天一数，收了 **90** 颗。」下方一排 **emoji 心情**（😊 😭 😤 😌 🤔），用户 **拖进右侧「秋天·收成筐」**（`DragTarget`）即完成（**无标准答案**，表达感受即可）。
- **动效与触感**：
  - emoji `Draggable`：`feedback` 略放大；筐在 `onWillAccept` 时 **边框金色 + 轻微弹跳**（`scale 1.0→1.04→1.0`，400ms）。
  - 落入筐：`HapticFeedback.selectionClick` + emoji 在筐内 **fade + scale** 出现一帧「已记录」对勾（400ms）。
- **Myo 反馈（拖入后）**：「收到你的心情啦～**少收几颗不代表春天白过**；重要的是：你知道这是 **一整季的结果**，不是某一天决定的。」

#### 6.4.4 通关结算

- 全屏烟花动画（1.5s，Lottie 占位可后续接入，目前已用 Flutter 动画实现）
- 中央显示："首次关卡全通！"
- Myo 站在花田中央欢呼（文案：「三关过完——本金、涨跌、盈亏，你都摸过一遍啦！」）

  - 耐心值扣除：爱心**碎裂 + 震动**（轻到不令人害怕）

### 6.6 `Onboarding_05_Reward_Reveal`（新增：概念卡收下仪式）

> 专门为"第一张概念卡的心理所有权"而设计的一步，避免奖励出现后立刻跳转造成突兀。

- **目的**：
  - 首次发放 `CARD-01 · 市场门口的第一步` 概念卡
  - 让用户主动点击「收下卡片」，形成“这是我获得的第一张卡”的拥有感
  - 作为进入首页前的轻量奖励确认，不再强制加入 Streak 点火环节
- **流程（单屏，不可跳）**：
**Phase 1：概念卡揭幕与收下**
  - 黑色半透明背景 + 中央光束
  - 卡片从下方升起，背面朝前
  - 用户点击屏幕任意位置 → 卡片翻转 → 显示 `CARD-01`
  - `CARD-01` 显示后进入**悬浮态**：卡片像奖励物一样在空中轻微上下浮动，提示“这是刚获得的卡片”
  - 底部文字："你获得了第一张概念卡，点击屏幕收下卡片"
  - 翻转动画结束后再次点击屏幕 → 卡片轻微缩小 + 淡出 → 进入下一界面
- **动效**：
  - 卡片翻转：3D flip 600ms + 边缘微粒子
  - 悬浮态：上下浮动约 ±7px，单次循环约 2.2s，缓慢、轻盈，不制造紧迫感
  - 收下卡片：scale 1.0 → 0.72 + opacity 1 → 0，约 420ms
- **音效**：
  - 卡片翻转：`card_flip.wav`
  - 收下卡片：`card_unlock_gentle.wav`
- **触感**：
  - 收下卡片：`success`（轻到中等），强调奖励落袋而不是刺激用户上瘾
- **为什么不可跳**：
  - 这是用户第一次建立“概念卡收藏”的心理所有权；跳过会削弱后续卡片收集反馈。

## 10. 防上瘾伦理边界

投资教育与语言学习最大的不同：**用户的行为影响真金白银**。以下红线**不可越**。

### 10.1 绝不做的事

1. **不**在 App 内设置**无限连抽 / 盲盒 / 翻牌**类机制。
2. **不**用"错过限时奖励"制造紧迫感。
3. **不**把**投资真实收益率**纳入排行榜或社交比较。
4. **不**用 Streak 绑架用户做**真实交易**（Streak 只与"学习"挂钩，**不与"下单"挂钩**）。
5. **不**鼓励用户超出月储蓄能力的投入——Starter Plan 推荐金额**永远≤ 用户自报储蓄的 30%**。
6. **不**在任何推送里出现"涨 / 跌 / 暴涨"等刺激词。
7. **不**搞大额现金红包 / 拉新返现（避免被"薅羊毛党"攻击 + 避免金融监管擦边）。

### 10.2 必须做的事

1. 设置里**可一键关闭**所有游戏化元素（**"静读模式"**），只保留纯学习内容。
2. **每 30 天**弹一次"你希望继续用游戏化方式吗？"的冷启动问卷（尊重用户自主权）。
3. 在**隐私/设置**页醒目展示**"我们不交易你的数据"**承诺。
4. 针对**未成年用户（18 岁以下）**：自动关闭排行榜 + 社交分享入口。
5. 推送频率**每人每天不超过 2 条**，系统级别硬限制。
