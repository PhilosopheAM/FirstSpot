# FirstSpot「我的持仓」功能与页面设计（V1）

> 文档目的：补齐「用户在 FirstSpot 内查看与分析自身持仓」的产品定义，为后续 Figma 原型与 Flutter 实装提供单一事实来源。  
> 范围：手动录入外部交易产生的持仓记录、资产总览、占比与结构可视化、轻量分析；**不包含** App 内下单、券商账户直连、实时成交同步（可作为 V2+ 扩展）。

---

## 1. 产品定位与原则

### 1.1 要解决的用户问题

- 用户在**多个渠道**（不同券商 App、银行理财、基金平台等）完成买卖后，资产分散在多处，难以形成**一张总账**。
- 小白用户更需要**一眼看懂**的「我现在有什么、各占多少、整体风险/结构是否偏科」，而不是专业交易终端式的表格堆砌。

### 1.2 FirstSpot 差异化约束（与现有产品一致）

- **教育 / 洞察优先**：页面默认呈现「结构与健康度」类信息，避免制造频繁交易的冲动。
- **非交易型产品**：录入的是「事实记录」，所有买卖均在站外完成；App 内不提供买卖按钮（可在文案中温和提示「请在你开户的平台操作」）。
- **可视化优先**：关键结论尽量由图表达，数字作为辅助与钻取详情。

## 2. 用户操作流程（UX 动线）

以下动线按「首次使用 → 日常使用 → 异常/维护」组织，便于拆屏幕与导航。

### 2.1 首次进入（冷启动）

1. **入口发现**  
   用户从主导航（如底部 Tab 或「工具 / 我的」聚合入口）进入「我的持仓」。
2. **空状态教育**  
   展示简短说明：「FirstSpot 不连接券商账户；你可以把在其他平台的买卖记在这里，形成自己的总仓位视图。」配一张示意插画（可为 Myo 拿账本/拼图类资产块）。
3. **引导第一次录入**  
   主按钮：**添加一笔持仓**（或「记一笔买入」）。次按钮：**稍后再说**（返回空状态，不强迫）。
4. **选择资产类型**（降低表单复杂度）  
   卡片式选择：**股票** / **基金（含 ETF）** / **现金类（货基、存款等简化记法）** / **其他**（V1 可先合并为「其他」或仅开放股票+基金）。
5. **填写交易事实**  
   分步或单页表单（见第 3 节字段）；支持「保存并继续添加」连录多笔。
6. **即时反馈**  
   保存成功后进入**持仓总览**，并用轻提示（Toast / 顶部横幅）说明「可随时在列表里编辑成本或数量」。

### 2.2 日常使用（热路径）

1. **打开总览**  
   默认落在「总览」Tab：总资产（估算）、当日涨跌（若可算）、结构图置顶。
2. **快速扫一眼**  
   用户 3 秒内应完成：**总金额量级** → **最大单一标的占比是否过高** → **股票/基金/现金比例**。
3. **钻取单标的**  
   点击列表行或图中扇区 → 进入**标的详情抽屉 / 子页**：成本、数量、浮动盈亏（口径见 3.3）、占组合权重、可选迷你走势（若已有行情数据源）。
4. **对比「目标结构」**（V1 可选 / V1.5）  
   若用户在学习模块中保存过「目标股债比」或模板，可在总览底部展示「当前 vs 目标」条形对比（不强依赖，避免阻塞 V1）。

### 2.3 维护与纠错（信任动线）

1. **编辑 / 删除**  
   列表左滑或进入详情后：编辑数量、成本价、买入日期；删除记录需二次确认（防误触）。
2. **分红送转 / 拆股**（V1 建议）  
   V1 可用「备注 + 手动改数量/成本」覆盖；独立「公司行动向导」可作为 V2，避免首版过重。
3. **数据口径说明**  
   总览页固定入口：**如何计算市值与盈亏**（底部文案链或「？」图标），降低「和券商不一致」的客服成本。

### 2.4 离开与回访

1. **下次打开**  
   本地或云端持久化后，直接进入总览（无空状态）。
2. **轻提醒（非推送轰炸）**  
   可选：「你已超过 N 天未更新持仓」——默认弱提示，避免焦虑。

## 3. 功能设计（基于动线拆解）

### 3.1 信息架构（建议一级结构）

| 模块 | 职责 |
|------|------|
| 总览 | 组合层面 KPI + 图表 + Top 列表入口 |
| 持仓列表 | 可排序、可筛选的全部标的 |
| 添加 / 编辑 | 表单与校验 |
| 分析（可与总览合并） | 行业/资产类别穿透、集中度风险提示 |
| 设置与说明 | 币种、涨跌色、成本算法、隐私说明 |

V1 可将「分析」折叠进总览下半屏，减少 Tab 数量。

### 3.2 核心实体与字段（手动录入）

**持仓记录（Position）建议字段**

- **资产类型**：枚举（股票 / 基金 / 现金类 / 其他）。
- **标的识别**：代码（如 `600519`）、市场（沪/深/北/场外基金代码等）、名称（可自动联想补全，V1 可手输）。
- **方向**：买入 / 卖出（V1 若只做「当前持仓快照」，可用「净持仓」简化：只录买入与减仓，卖出用减仓事件；产品需二选一并写清）。
- **数量**：股数 / 份数；精度规则按类型定义。
- **成交价格**：单价；支持「总价反推单价」辅助输入。
- **成交日期**：用于持有期展示与排序。
- **成本类型**（可选）：含费成本 / 不含费；手续费（可选字段）。
- **备注**：自由文本（如「华泰」「定投」）。
- **货币**：默认 CNY；多币种为 V2。

**组合（Portfolio）**

- V1 默认单组合即可；预留「子账户 / 分组合」为扩展。

### 3.3 计算与展示口径（必须在文档与 UI 中一致）

- **市值**：最新价 × 数量（最新价来源：接入行情则实时；未接入则显示「按最后录入价格」并明确标注「未刷新」）。
- **权重**：单标的市值 / 组合总市值。
- **浮动盈亏**：`(最新价 - 成本价) × 数量`；成本价定义与分红送转处理需在「说明」页写明。
- **现金类**：可简化为「金额面值」一条记录，不参与股价波动，仅参与占比饼图。

### 3.4 校验与防错

- 数量、价格必须 > 0；日期不得晚于今天（或允许未来交割？默认不允许）。
- 卖出数量不得超过当前可用数量（若采用事件流模型）。
- 删除与批量操作需确认。

### 3.5 权限与隐私（产品层）

- 默认本地存储 + 可选登录云同步（若产品已有账号体系）；文档中标注「敏感财务数据」处理原则。

## 4. 页面设计描述（最大化可视化 + Figma 预备）

以下按屏幕描述**布局层级、组件形态、数据绑定与交互**，便于在 Figma 中建 Frame、Auto Layout 与组件集。

### 4.1 设计关键词（视觉方向）

- **一张总图讲清结构**：首屏 50% 以上垂直空间给「组合结构」与「总资产」叙事，避免首屏全是表格。
- **从总到分**：环形图 / 树图 → 列表 → 详情抽屉；同一指标在三层之间**数值一致、颜色编码一致**。
- **少表格、多条形**：列表中用「迷你条」表示权重，而不是让用户自己比对两列数字。
- **与个股页对齐**：涨跌色、圆角、留白、图表平滑曲线等延续 `stock-detail-page-design.md` 与金融小组件页的 FirstSpot 家族感。

### 4.2 屏幕 A：持仓总览（Home）

**布局（自上而下）**

1. **顶栏**  
   标题「我的持仓」；右侧「+」进入添加流程；次级「⋯」进入设置/说明。

2. **Hero 区（强可视化）**  
   - **左侧（或上部）**：大字「总资产（估算）」+ 辅助一行「较成本 +X / -Y（Z%）」用颜色区分。  
   - **右侧（或下部）**：**环形图（Donut）** 表示大类占比：**股票 / 基金 / 现金 / 其他**。环心可放「标的数量」或「组合健康度」简标（如「偏股」）。  
   - 交互：点击某一扇区 → 筛选下方列表为该大类；再次点击恢复全部（或提供 Chip 筛选条）。

3. **二级结构图（可选与 Hero 二选一或 Tab 切换）**  
   - **条形堆叠（100% Stacked Bar）**：展示「行业」或「宽基主题」占比（需标的映射数据；V1 若无行业数据，可用「用户自定义标签」条形图替代）。  
   - 或 **Treemap**：面积 = 权重，适合标的数 ≤ 20；过多时合并为「其他」。

4. **风险/集中度一眼条（可视化组件）**  
   - **Top1 / Top3 权重**横向进度条 + 阈值色（绿/黄/红）：例如 Top1 > 40% 黄、> 60% 红（阈值可在说明页解释「经验规则非投资建议」）。

5. **持仓列表（半可视化）**  
   每行：**图标 / 首字圆标**、名称+代码、**权重条**、市值、当日涨跌（若有行情）。  
   排序 Chip：**按权重 / 按市值 / 按当日涨跌 / 按名称**。

6. **底部**  
   Myo 弱陪伴：一句情境文案（如「结构比预测更重要」），不占主操作区。

**Figma 建议**  
- Frame：`Portfolio / Overview`；Donut 与 Stacked Bar 各做一组 Component Variant（有数据 / 空数据 / 单一大类）。  
- 为列表行建 `ListRow_Position`：含 `weight_bar` 子组件（固定宽底条 + 百分比填充）。

### 4.3 屏幕 B：添加持仓（分步向导）

**Step 1 类型选择**  
大卡片四宫格，插画小标 + 一行说明。

**Step 2 标的搜索**  
搜索框 + 联想列表（Figma 用重复网格占位）；无结果时展示手动录入完整字段。

**Step 3 成交信息**  
表单：数量、价格、日期；**实时迷你预览条**：「预估权重 = x%（基于当前组合）」增强反馈。

**Step 4 确认**  
摘要卡 + 主按钮「保存」；次按钮「再记一笔」。

**Figma 建议**  
- 使用 `Wizard_Step1..4` 组件；进度指示用 Stepper（4 点）。  
- 关键数字用 `Number` 样式与等宽数字（tabular figures）避免抖动。

### 4.4 屏幕 C：标的详情（子页或 Bottom Sheet）

- 顶部：名称、代码、类型标签。  
- **小型折线**：「自买入以来」或「近 1M/3M/1Y」（与行情能力对齐）。  
- **指标卡片（2×2）**：成本价、数量、市值、权重、浮动盈亏。  
- **历史操作时间线**（V1.5）：买入/卖出点；V1 可仅显示创建记录。  
- 底部主操作：**编辑**、**删除**（删除红色文字按钮）。

### 4.5 屏幕 D：分析（可与总览同页折叠区）

- **集中度曲线**：横轴标的排序，纵轴累计权重，形成 Lorenz 式累计曲线（简化版：前 N 名累计占比折线）。  
- **相关性/波动**为 V2+；V1 不做复杂量化。

### 4.6 空状态与错误状态

- **空状态**：插画 + 两句文案 + 主按钮「添加第一笔持仓」。  
- **无行情**：图表区展示「虚线占位」+ 标签「暂无最新价，显示为录入价」。  
- **加载**：骨架屏按 Hero、图、列表三块分区。

### 4.7 无障碍与可读性（Figma 约束）

- 图表不仅依赖颜色：扇区带**图案纹理**或**序号标签**。  
- 触摸目标 ≥ 44pt；列表行整行可点。

## 5. 与现有 FirstSpot 模块的关系

- **个股洞察 / 详情**：从持仓列表点击股票可跳转已有 `stock_insight` 模板页（若代码已接 symbol），形成「我的组合 → 单票研究」闭环。  
- **投资者教育**：在集中度超阈值时，可露出「相关章节：搭建稳健组合」轻链（非阻断弹窗）。  
- **金融小组件**：持有成本、复利工具与持仓页的「成本价、持有期」叙事一致，文案上避免两套口径。
