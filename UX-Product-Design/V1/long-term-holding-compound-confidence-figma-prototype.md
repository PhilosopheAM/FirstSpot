## 3. 产品目标与用户心理

- **目标用户**：刚开始长期配置 ETF、基金或核心股票的新手投资者。
- **核心问题**：用户容易被短期盈亏牵引，无法把“已经坚持的天数”和“长期收益路径”联系起来。
- **页面目标**：把持仓从“今天涨跌多少”转换为“我已经坚持了多久、组合结构是否稳、预期路径完成到哪里、继续持有一天的复利意义是什么”。
- **情绪基调**：稳定、温暖、可信赖；避免刺激交易，不使用夸张收益承诺。

## 4. 数据与计算口径

### 4.1 持仓分布

- **输入字段**：
  - 标的名称：`assetName`
  - 当前市值：`marketValue`
  - 仓位占比：`weight = marketValue / totalMarketValue`
- **可视化方式**：环形饼图 + 图例百分比。
- **设计目的**：帮助用户先理解组合结构，而不是被单一标的波动放大焦虑。

### 4.2 预期收益率与当前达成率

- **输入字段**：
  - 年度预期收益率：`expectedAnnualReturn`
  - 当前已达成收益率：`currentReturn`
  - 可选目标上限：`returnScaleMax`，当前原型以 `25%` 作为视觉比例尺。
- **可视化方式**：同一横条中用深色表示已达成，用浅色表示预期区间，并用竖线标出目标位置。
- **设计目的**：让用户理解“当前收益只是长期路径上的位置”，减少把短期回撤误读为长期计划失败。

### 4.3 潜在每日复利收益

- **示例口径**：
  - 当前本金：`principal = ¥82,400`
  - 组合预期年化：`expectedAnnualReturn = 16.8%`
  - 潜在每日复利收益：`dailyPotential = principal * ((1 + expectedAnnualReturn)^(1 / 365) - 1)`
- **当前展示**：约 `+¥35`，用于解释“多坚持一天，复利曲线多长出一点”。
- **合规边界**：必须标注为“基于预期的情景估算 / 心理锚点”，不能表达确定收益、保本收益或每日真实到账收益。

## 5. 设计语言

- **色彩**：奶油底色承接 FirstSpot 温暖感；绿色作为长期复利与坚持主色；金色、蓝色、红色用于区分不同持仓类别。
- **图形**：大圆角卡片、柔和阴影、环形饼图、低对比进度条，减少金融界面的压迫感。
- **文案**：使用“路径、坚持、节奏、估算、波动”等词汇，避免“稳赚、暴涨、躺赚”等诱导性表达。
- **字体**：Figma 原型使用 `Noto Sans SC` 修复中文渲染，便于跨平台评审。

## 6. 后续可交互方向

1. **时间范围切换**：切换 `近30天 / 近1年 / 持有以来`，观察当前达成率变化。
2. **复利路径模拟**：点击 `查看复利路径` 展示 1 年、3 年、5 年情景曲线。
3. **标的下钻**：点击某个饼图图例或收益率条，进入该标的的详情解释。
4. **风险提示弹层**：当用户查看预期收益时，展示“预期不等于承诺，真实收益会波动”的解释。
5. **Myo 陪伴提示**：后续可加入 Myo 用一句话解释“今天为什么值得继续坚持”。
